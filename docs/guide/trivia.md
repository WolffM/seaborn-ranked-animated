# Trivia

The best facts about this repo, each with its source.

- The repo's first commit, 22,645 lines across 7,782 files, already
  included 7,762 match-history JSON files — one per League of Legends
  game — checked straight into git (`adc6757`).
- Its busiest day, 2023-11-09 (8 commits), relocated the entire
  match-file collection in two steps three minutes apart: one commit
  deleted 7,528 old-location files, 13,983 lines (`c2c14ac`, 11:51), the
  next added 7,765 files at the new one, 15,526 lines (`67e83f1`, 11:54).
- The project was once hosted at `github.com/WolffM/riotdata`; its own
  README still introduces it as "riotdata" rather than its current repo
  name (`d7f1279`, `f9213aa`).
- After 778 days with no commits (`c82ba79` to `fc8f9b4`), the next
  commit added 198 more match-history JSON files rather than fixing
  anything (`fc8f9b4`); only the eight commits after that were automated
  maintenance — an automated README tagline (2026-01-05), a lint
  workflow added and later removed, and two automated lint fixes
  (2026-01-07, 2026-01-13).
